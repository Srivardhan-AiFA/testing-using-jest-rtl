# 📒 Notely

This is the **backend API** for **Notely**, a notes management application built with **Express, TypeScript, and MongoDB**.  
It provides **CRUD operations** for managing personal notes with JWT-based authentication.

---

## 🚀 Features

- 🔑 User authentication (JWT)
- ➕ Create notes
- 📜 Get all notes
- 📄 Get a single note
- ✏️ Update notes
- 🗑️ Delete notes

---

## ⚙️ Tech Stack

- **Node.js** + **Express.js**
- **TypeScript**
- **MongoDB** + **Mongoose**
- **JWT Authentication**
